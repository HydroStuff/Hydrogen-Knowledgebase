Frequently Asked Questions
How to download and use Hydrogen?

Requirements

  • macOS 11+
  • Administrator account

Installation

  1. Run the install script
    • Copy the script from this channel
    • Paste it into your terminal and press Enter
  2. Enter your password
    • Type in your password, keep in mind that it won’t be visible
    • Press Enter
  3. Wait for completion
    • Wait for the script to install Hydrogen
    • After installing close the terminal

Usage

  1. First steps
    • Open Roblox
    • Paste your key in the pop-up window
  2. Executing scripts
    • Open Hydrogen-M
    • Paste your script
    • Join a game
    • Press the “Execute” button on the bottom right
How to get a free key?

You will need go to the key system and complete a few offers. You don’t need to install anything from the offers except browser extension. The offers fall into four main categories:

Articles

  • Click on an article
  • Wait for 45 seconds
  • Go to the next step

App Downloads

  • Click the download button and stay on the download page for 45 seconds
  • Return to Work.ink after 45 seconds
  • Delete the downloaded file

Browser Extensions

  • Install the extension
  • Return to Work.ink
  • Remove the extension after step completion

Sign Ups

  • Click the sign up button
  • Go to the website and stay there for 45 seconds
  • Return to Work.ink after 45 seconds

Extra

  • Don’t switch back to Work.ink before the 45 seconds are up or you will have to start over
  • Use Chrome without ad blockers or any extensions that might interfere with Work.ink
  • This shouldn’t take longer than 5 minutes, if it does you’re probably doing it wrong

How to remove Hydrogen?

To remove or reinstall Hydrogen from your Mac, run the script below in your terminal.

cd && curl -LJs "https://raw.githubusercontent.com/nullstate9/roblox-stuff/refs/heads/main/executors/hydro-uninstaller.sh" -o "./hydro-uninstaller.sh" && chmod +x hydro-uninstaller.sh && sudo ./hydro-uninstaller.sh

The script removes the app, and reinstalls the normal version of Roblox. It does keep the Hydrogen folder in application support and your home directory, if you would like to completely remove Hydrogen, delete both Roblox and Hydrogen along with their folders and then reinstall Roblox from the official website.

Is my Mac supported?

Both Intel and Silicon Macs are supported, as long as they are running macOS 11 or newer (Tahoe is semi-broken, works for some people doesn't for others). You can check your version by typing sw_vers in the Terminal app.

Permission denied (os error)

To fix this error make sure that you are on an administrator account and that the Terminal app has Full Disk Access.

Check if you are an administrator

  1. Open Settings and go to “Users & Groups”
  2. Check if your account is listed as an Admin

Give Terminal Full Disk Access

  1. Open Settings and go to “Privacy & Security”
  2. Go to “Full Disk Access”
  3. Press the plus icon at the bottom
  4. Add Terminal to the list

How to change DNS

To change your DNS open Settings and go to “Wi-Fi” then press the details button and go to the “DNS” tab. Set your primary dns to 1.1.1.1 by pressing the plus icon to add a new address, make sure it’s the first one in the list.
