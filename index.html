Installation & Usage

Requirements

  • macOS 11.7.1+
  • Administrator account

Installation

  1. Run the install script
    • Copy the script from this channel
    • Paste it into your terminal and press Enter
  2. Enter your password
    • Type in your password (it won't be visible)
    • Press Enter
  3. Wait for completion
    • Wait for the script to install Hydrogen
    • After installing, close the terminal

First Steps

  • Open Roblox
  • Paste your key in the pop-up window

Executing Scripts

  • Paste your script
  • Join a game
  • Press the "Execute" button on the bottom right
